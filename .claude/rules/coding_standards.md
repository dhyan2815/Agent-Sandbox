# Coding Standards

This repository has no source code directory (`src/`) and no programming-language files to apply style rules to — it is a skills/content/workflow repo. Generic language style guides (PEP 8, Prettier/ESLint, gofmt, etc.) were removed from here since Claude already follows them by default and there's nothing in this repo for them to apply to.

If a language-specific project is added under this repo, restore concrete standards here scoped to that subdirectory.

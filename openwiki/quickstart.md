# Agent Sandbox Overview

Agent Sandbox is an experimental environment for developing and testing AI agents, machine learning models, and Python coding solutions. It combines practical coding playgrounds with agent automation frameworks to enable rapid iteration and exploration of agent-based workflows.

## Repository Structure

1. [**/docs/**](openwiki/docs.md) - Research and experimental documentation
2. [**/playground/**](openwiki/playground.md) - Coding and ML experimentation
3. [**/visuals/**](openwiki/visuals.md) - Architecture diagrams and workflows
4. [**/agent/**](openwiki/agent.md) - Agent framework documentation

## Getting Started
- Explore `/playground/` for hands-on coding exercises
- Review `/visuals/` for system architecture references
- Consult `/agent/` for agent implementation guidelines
- See `/docs/` for technical documentation and experiment reports

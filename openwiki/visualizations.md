# Visualizations

This section documents the visual diagrams used throughout the Agent Sandbox repository.

## Diagram Types

- **Excalidraw**: Hand-drawn style diagrams for architecture and workflows (e.g., `visuals/cross-tool-workflow.excalidraw`, `visuals/mcp-server-architecture.excalidraw`).

- **Mermaid**: Architecture and sequence diagrams written in Markdown (e.g., in `docs/architecture/mcp-server-architecture.md`).

## Creation Process

- Excalidraw diagrams are created using the Excalidraw application and exported as `.excalidraw` files stored in the `visuals/` directory.

- Mermaid diagrams are written in Markdown files and rendered in documentation (e.g., `docs/experiments/mermaid-diagram-generation.md`).

## Key Diagrams

- **Cross-tool Workflow**: `visuals/cross-tool-workflow.excalidraw` - Shows interactions between different AI CLI tools.

- **MCP Server Architecture**: `visuals/mcp-server-architecture.excalidraw` - Visual representation of the MCP server structure.

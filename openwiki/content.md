# Content Creation

This section covers content creation workflows, including LinkedIn automation, post writing, graphic design, voice profiling, and more.

## LinkedIn Automation

- **Profile Optimization**: Use `linkedin-profile-optimizer` to rewrite profiles for conversion-focused URLs.
- **Comment Generation**: Generate non-generic engagement comments with 15 variants covering mood, humor, and analytical connectors.
- **Post Writing**: Create LinkedIn posts using `post-writer` with authentic voice generation.
- **Carousel Creation**: Build LinkedIn carousels (1080×1350) with `gemini-carousel`.
- **Quote Graphics**: Generate quote graphics paired with Gemini prompts via `quote-post`.
- **Thumbnails**: Create CTR-optimized thumbnails with `youtube-thumbnail`.
- **Reels Scripting**: Write Reel scripts from reference content using `reels-scripting`.
- **Newsletter Voice**: Profile newsletter-specific voice with `newsletter-voice`.

## Post Writing & Formatting

- **Authentic Voice**: Use `voice-builder` to establish a consistent brand voice.
- **Formatting Frameworks**: Apply PAS/AIDA/STAR/SLAY frameworks with `post-formatter`.
- **Scoring**: Evaluate content quality with `post-scorer` against performance benchmarks.
- **Idea Matrix**: Generate 32 post ideas from content pillars using `content-matrix`.

## Graphic Design

- **HTML/CSS**: Create responsive layouts with `graphic-designer`.
- **SVG Vector Graphics**: Produce scalable vector graphics using `graphic-designer`.
- **Design Systems**: Maintain consistent visual identity with `canvas-design`.

## Voice Profiling

- **Personal Voice**: Build a distinctive voice profile using `voice.md`.
- **Consistency Checks**: Regularly audit content for AI artifacts using `humanizer`.
- **Brand Alignment**: Ensure all content aligns with brand guidelines in `brand-kit.md`.

## Workflow Summary

1. **Plan**: Use `content-matrix` to brainstorm topics.
2. **Write**: Apply `post-writer` and `post-formatter` for structure.
3. **Refine**: Use `post-scorer` to evaluate effectiveness.
4. **Visualize**: Generate graphics with `graphic-designer`.
5. **Publish**: Schedule posts via `linkedin-comment-generator` and `linkedin-profile-optimizer`.
